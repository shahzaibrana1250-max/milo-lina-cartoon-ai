# User Guide — Milo & Lina Kids Cartoon Studio (Android)

## 1. Open the app

Open the GitHub Pages link in Chrome on your Android phone. For quick access,
use Chrome's menu → **Add to Home screen**. The app works like a normal app
from then on.

## 2. Start a project

- **Projects** tab → fill in a title (or leave it blank for an automatic one),
  pick a theme or "Surprise me", choose scene count (4–6) and scene length
  (10, 12, or 15 seconds).
- Tap **Create project**. A sample story is already waiting on first run.

## 3. Check and edit your characters

- **Characters** tab → Milo, Lina, and Bobo.
- Edit a description once; every prompt in every project reuses it.
- Tap the file button to upload a reference photo/drawing. It is saved in
  this browser and reused. Use **Remove reference image** to clear it.

## 4. Generate a story

- **Story** tab → read the beats, dialogue, and moral.
- **Generate new story** makes a different story with the same structure.
- Stories always follow: happy hook → problem → brave attempt → surprise
  twist → happy ending.

## 5. Edit scenes

- **Scenes** tab → each card is one 10–15 second scene with a 9:16 preview box.
- Edit the title, event, feeling, camera, sound, length, or dialogue lines
  (write dialogue as `Name: line`, one per line).
- Move scenes up/down, delete them, or add a new one. Continuity lines update
  automatically: every scene opens where the previous one ended.

## 6. Preview and export prompts

- **Prompts** tab → read each scene's full prompt before exporting.
- **Copy this prompt** copies one scene. **Copy ALL prompts** copies the whole
  pack in one tap — paste it into Kling, Runway, Hailuo, or any video
  generator, one scene at a time, in order.
- **Download prompt pack (.md)** saves the same pack as a file.
- **Download project (.json)** is your full backup.

## 7. Make a video (Video tab)

- **Play with voices** plays the whole project: animated scenes, subtitles,
  spoken dialogue (free voices built into your phone), mood-matched music,
  and sound effects for surprises, discoveries, and happy endings.
- **Music volume** slider keeps music under the dialogue. Music also dips
  automatically whenever a character speaks.
- **Character voices** — pick a voice, pitch, and speed per character, and
  use the Test button to hear each one. Lines are shaped by emotion:
  excited lines sound higher and faster, sad lines lower and slower.
- **Record video** records the same playback and lets you download a .webm
  file. The download contains the music + sound effects mix and subtitles.
  Spoken voices play live only and are not in the download (a browser
  limit — device speech cannot be recorded by a page). Convert .webm to
  .mp4 with a free converter if Shorts needs .mp4.
- **Real AI video (optional)** — MiniMax H3 can render true AI motion for a
  scene. It is paid (~$0.08/second at 768p, no free tier), needs your own
  key, and is untested until you try it. Start with the Scene 1 test button.

## 8. Back up regularly

Your projects live in this browser only. After finishing a project, download
its JSON backup. If you ever clear browser data or switch phones, import that
JSON back (Projects tab → Import project JSON) and re-upload reference images.

## Tips

- Keep one main event per scene — generators handle single actions best.
- Keep dialogue to 1–2 short lines per scene for clean lip-sync later.
- Vertical 9:16 and the style lock are already inside every prompt.
